# Project Board (Documentation)

This repository can be managed with the following board lanes:

1. **Backlog**
2. **Ready**
3. **In Progress**
4. **Review**
5. **Done**

## Recommended Labels

- `type:bug`
- `type:feature`
- `type:docs`
- `type:security`
- `priority:high`
- `priority:medium`
- `priority:low`

## Suggested Automations

- New issue -> Backlog
- Linked PR opened -> In Progress
- PR in review -> Review
- PR merged -> Done
